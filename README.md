# Презентації ООП — дизайн і керування із sample.zip

Файли lect_8.html, lect_9.html, lect_10.html перетворено під структуру презентацій із sample.zip.

## Спільні файли
- style.css — оригінальні стилі sample.zip.
- script.js — навігація й огляд із sample.zip (без змін).
- oop.css — адаптаційні стилі для вмісту лекцій 8–10, також замінює всі колишні inline style.
- oop.js — ініціалізація Highlight.js, відповіді на запитання й скидання прокрутки.
- logo.png — логотип із sample.zip.
- highlight.min.js, highlight-theme.css — локальна бібліотека Highlight.js і темна тема.

Синтаксис C# підсвічує локальна версія Highlight.js 11.0.1 (BSD-3-Clause), тема Atom One Dark Reasonable. Файли highlight.min.js і highlight-theme.css включені до архіву, тож для підсвічування не потрібен Інтернет. Зовнішній Google Fonts має системні fallback-шрифти.

Для перегляду зберігайте HTML, CSS, JS, logo.png в одній папці. У Moodle завантажте архів як ресурс «Файл» (розпакування) або розмістіть як HTML-пакет так, щоб шляхи до цих файлів збереглися. Просте вставлення вихідного HTML до редактора Moodle може видалити script і не підключить зовнішні файли.

Керування: ←/→, пробіл, Home/End, O — огляд, F — повний екран, кліки на стрілках. Хеш #slide-7 відкриває конкретний слайд.

## Збільшення коду (оновлення)
Шрифт у блоках C# збільшено приблизно на 22% (з `.78em` до `.95em` відносно базового розміру контенту). Довгі фрагменти прокручуються всередині слайда; горизонтальна прокрутка залишається доступною для довгих рядків. Для коригування розміру змініть `font-size` у правилі `.slide .legacy-content pre` файлу `oop.css`.

Highlight.js збережено локально навмисно: стабільна версія, відсутність залежності від CDN, робота в автономному режимі (якщо сторінку вже завантажено). За потреби бібліотеку та тему можна підключити через CDN, але тоді підсвічування залежатиме від доступу до стороннього сервера.
