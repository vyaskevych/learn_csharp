Подія і делегат: у чому різниця?

EventHandler

Делегат — тип, який визначає, які методи можна викликати (сигнатуру).

event

Подія — механізм сповіщення, до якого можуть підписатися методи сумісного типу.

public event EventHandler? Changed;
// Сигнатура сумісного методу:
void OnChanged(object? sender, EventArgs e)

У Windows Forms події компонентів уже оголошені: зазвичай ми підписуємо обробник, а не створюємо власну подію.

Що означають sender та e?

sender

sender — хто викликав обробник. Якщо один метод підписано на події кількох елементів, він допомагає розрізнити джерело.

EventArgs

e — додаткові дані події. Для Click часто вистачає EventArgs; у KeyDown доступний e.KeyCode.

Важливо: якщо обробник працює лише з одним елементом і джерело не має значення, використовувати sender всередині методу необов’язково.

private void ToggleControls()
{
    bool toKmh = rbToKmh.Checked;
    textBox1.ReadOnly = !toKmh;

    txtResult.Clear();

Введення

Активне поле: ReadOnly = false; можна вводити, фокусувати та копіювати.

Поле результату: ReadOnly = true; можна виділити й скопіювати число.
